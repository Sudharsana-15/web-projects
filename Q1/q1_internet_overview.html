A quick primer for understanding how the web works, prepared for the institution's website planning phase.

Internet Overview

The Internet is a vast global network of interconnected computers that communicate using standardized protocols (TCP/IP) to exchange data, resources, and services across the world.

Fundamental Computer Network Concepts

Node — any device connected to a network  •  IP Address — unique identifier for each device  •  Protocol — rules for communication (HTTP, TCP/IP)  •  Bandwidth — data transfer capacity

Domain Name

A domain name (e.g. example.com) is a human-readable address mapped to a numeric IP address via DNS (Domain Name System), so users don't need to remember IP numbers.

Web Browsers and Web Servers

Web Browser: Client software (Chrome, Firefox) that requests and renders web pages.

Web Server: Software/hardware (Apache, Nginx) that stores and delivers web pages on request.
